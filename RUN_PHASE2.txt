PHASE 2 - PREPROCESSING

From the Brain_Connectome_Analysis project root:
    pip install numpy pandas scipy matplotlib
    python -m src.preprocessing.preprocessing_pipeline

Default input:
    data/synthetic/synthetic_fmri.csv

Default outputs:
    data/processed/synthetic_fmri_preprocessed.csv
    data/processed/normalization_statistics.csv
    data/processed/preprocessing_report.json

To skip filtering:
    python -m src.preprocessing.preprocessing_pipeline --no-filter

The default band-pass is 0.01-0.10 Hz with TR=2 seconds. This is a demonstration
choice for this synthetic dataset, not a universal setting for every fMRI study.
